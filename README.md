## 🚀 Projets

### 🛒 STIMULATION CAISSE — Système de Gestion de Caisse

**Statut :** ✅ Terminé — Prêt pour déploiement

Application complète de gestion de point de vente (caisse) pour supermarché, avec double backend (SQLite/PostgreSQL), interface web Flask pour les caissiers et interface CLI pour l'administration.

| Aspect | Détail |
|--------|--------|
| **Backend** | Python 3.14, Flask, SQLite / PostgreSQL |
| **Frontend** | HTML/CSS/JS (interface caisse web), CLI (admin) |
| **Analyse** | Pandas, NumPy, Matplotlib — rapports CSV |
| **BDD** | SQLite (local) ou PostgreSQL (professionnel_db) |
| **DBeaver** | Script d'auto-configuration de connexion |
| **Architecture** | Modular (database.py, caisse.py, orders.py, analysis.py) |

**Fonctionnalités clés :**
- 🖥️ **Interface caisse** (Flask) : catalogue produits, panier, lookup client par CNI, ticket de caisse
- 👤 **Gestion clients** : base avec CNI comme identifiant unique
- 📦 **Gestion produits** : 20 produits informatiques avec stocks
- 📊 **Analyse de données** : pandas/numpy — CA, panier moyen, percentiles, classement produits, tendances
- 🔄 **Dual backend** : bascule SQLite ↔ PostgreSQL
- 🔌 **Auto-config DBeaver** : création utilisateur + base + connexion en 1 clic

**Dépôt :** `stimulation_caisse/`

### 🤝 CONNECT-PRO — Plateforme de Matching Startups & Investisseurs

**Statut :** ✅ Déployé — [Demo live](https://connectpro-eight.vercel.app)

Plateforme de mise en relation intelligente entre startups et investisseurs utilisant un algorithme TF-IDF et similarité cosinus pour calculer des scores de compatibilité.

| Aspect | Détail |
|--------|--------|
| **Frontend** | React (SPA), PWA, responsive |
| **Backend** | Flask, REST API (7 endpoints) |
| **Matching** | TF-IDF + Cosine Similarity (scikit-learn) |
| **Base de données** | PostgreSQL (Neon.tech) |
| **Déploiement** | Vercel (1-click deploy) |
| **Sécurité** | JWT, CORS, dotenv |

**Fonctionnalités clés :**
- 📊 Dashboard interactif avec vue globale startups/investisseurs/matchs
- 🧠 Algorithme de matching intelligent (secteur, compétences, localisation)
- 🔌 API REST documentée
- 📱 PWA installable sur mobile et desktop
- 🚀 Déploiement 1-clic sur Vercel

**Dépôt :** [AB-cloud-cyber/CONNECT-PRO](https://github.com/AB-cloud-cyber/CONNECT-PRO)
