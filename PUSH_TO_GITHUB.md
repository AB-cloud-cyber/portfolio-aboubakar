# 🚀 Publier le portfolio sur GitHub

## 1. Créer le dépôt sur GitHub

1. Va sur https://github.com/new
2. Nom du dépôt : **portfolio-aboubakar** (ou `ABOUBAKAR-MOHAMAN-portfolio`)
3. Description : "Portfolio — Projets STIMULATION CAISSE & CONNECT-PRO | Étudiant Génie Informatique IUT de Douala"
4. Public
5. Ne pas cocher "Initialize with README" (on a déjà le nôtre)
6. Cliquer sur "Create repository"

## 2. Pousser les fichiers en local

Ouvre **Git Bash** ou **PowerShell** dans ce dossier (`portfolio-aboubakar/`) et exécute :

```bash
git init
git add .
git commit -m "Initial commit: portfolio - STIMULATION CAISSE & CONNECT-PRO"
git branch -M main
git remote add origin https://github.com/AB-cloud-cyber/portfolio-aboubakar.git
git push -u origin main
```

> ⚠️ Remplace `AB-cloud-cyber/portfolio-aboubakar.git` par le nom exact de ton dépôt.

## 3. Ajouter le lien dans le CV

Le lien du dépôt : `https://github.com/AB-cloud-cyber/portfolio-aboubakar`
